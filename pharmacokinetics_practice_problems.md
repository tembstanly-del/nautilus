## Formula Reference Sheet

**Use these formulas to solve the problems:**

```
Vd = Dose / C₀

Cl = k × Vd
Cl = Dose / AUC

k = Cl / Vd
k = 0.693 / t½

t½ = 0.693 / k
t½ = (0.693 × Vd) / Cl

C(t) = C₀ × e^(-k×t)
[For half-lives: C(t) = C₀ × (0.5)^n where n = number of half-lives]

Css = R₀ / Cl

Loading Dose = Vd × Ctarget

F = (AUC_oral × Dose_IV) / (AUC_IV × Dose_oral)

Dose_oral = Dose_IV / F
```

**Constants:**
- ln(2) = 0.693
- Time to steady-state ≈ 5 × t½
- Time to eliminate ≈ 5 × t½
